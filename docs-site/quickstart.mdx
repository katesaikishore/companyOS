## 1. Install

Follow [Install](/install) for your platform. On macOS, the app asks for Automation permission for System Events, because that is how it reads which app is in front.

## 2. Finish setup

The first launch opens a short setup wizard:

1. **Welcome.** It explains what is recorded and what is not.
2. **What companyOS can see.** It explains the Automation permission on macOS and the keyring requirement on Linux.
3. **Your device and models.** It detects your hardware and recommends the models that fit it. Installing a model is optional, and each download is checked against its SHA-256 digest and written to the network ledger.
4. **Start observing.** Capture starts only when you choose it.

Nothing runs unless you start it, or you have turned on unattended runs for an automation at level 4.

## 3. See the first routine

Keep working as you normally do. After the same sequence repeats on three different days, the Suggestions page offers it. Accepting it creates a draft automation at level 2. You can dry-run the draft at any time. To run it for real, raise it to level 3 and start each run yourself.

## 4. Stop everything

**Stop all automations** in the sidebar turns every automation off at once. Pause capture from the same sidebar whenever you want the twin to stop noticing.
