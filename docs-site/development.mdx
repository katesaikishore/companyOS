## Layout

- `packages/core`: the twin engine: redaction, the store, segmentation, mining, automations, policy, autonomy and naming.
- `apps/desktop`: the Electron app. `src/main` is the main process, `src/renderer` is the interface, and `test/e2e.cjs` is the end-to-end script.
- `apps/browser-ext`: the Chrome and Edge extension and its native messaging host.
- `tests/privacy`: the planted-canary suite, which checks that nothing private reaches an output.
- `scripts/measure`: a CPU and memory sampler for the resource budgets.
- `docs`: the plan and research notes. `docs-site` is this documentation.

## Commands

You need Node.js 22 or later.

```bash
npm ci
npm run typecheck
npm test
npm run test:privacy
npm run build
npm start
```

`npm run dist:dir` builds an unpacked app for the current system. `npm run dist` builds the installers. `npm run measure` runs the sampler against the built app.

## End-to-end tests

The end-to-end script launches the built app through Electron and drives it with Playwright. It covers setup (including the optional decision-model step), the overview, suggestions, automations, the tray, the network ledger, Delete everything, and the fixed 900 by 600 window. It checks that every main route fits the window with no sideways scroll, and that the window cannot be resized, maximised or made full screen.

Playwright is not a dependency of the repository, so install it outside the tree:

```bash
npm run build
npm install --no-save playwright
NODE_PATH=$(npm root)/node_modules node apps/desktop/test/e2e.cjs
```

The script uses a temporary data folder, and it needs network access to huggingface.co to download the embedding model. The decision-model step does not use the network: the script starts a local server with a 3 MB bundle and points the app at it through `COMPANYOS_TEST_LAYA_FIXTURE`, which a packaged build ignores.

## Decision-model tests

`apps/desktop/test/laya.test.ts` tests the bundle manager against a local server that stands in for Hugging Face. It never downloads the real bundle. One opt-in test uses the real bundle already on your machine. It reads the files, checks them against the pinned digests, loads the model and asks one question:

```bash
COMPANYOS_REAL_LAYA=1 COMPANYOS_LAYA_CACHE=/path/to/cache npm test -w @companyos/desktop -- laya
```

The cache folder holds `receptron--laya-onnx/<commit>/`, the layout the `@receptron/laya` package uses. The test only reads it.

## Continuous integration

`.github/workflows/ci.yml` runs on every push and pull request. It runs the typecheck, the unit tests, the privacy suite, the build and an unpacked package on Ubuntu, macOS and Windows. The end-to-end script runs on Linux under a virtual display.
